# Changelog

All notable changes to Arigami. Generated by `bun run release` from conventional commits; newest first.

## v0.1.0 — 2026-09-08

The first numbered version — everything up to this point (the pre-release history). From here on every release is minted with `bun run release <patch|minor|major>`, which bumps `package.json`/`VERSION`, writes this file from the conventional commits since the previous tag, commits and tags `vX.Y.Z`; pushing the tag makes CI publish the GitHub Release and the images.
